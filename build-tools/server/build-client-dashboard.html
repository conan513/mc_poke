🐧 Linux - Összes Formátum
📦
Arch Linux
pacman csomag
Arch Linux felhasználók számára optimalizált csomag. Közvetlenül pacman-ből telepíthető.
📝 Build / Másolás
./build-client-linux-arch.sh
💾 Telepítés
sudo pacman -U Cobblemon-Universe-x64.pacman
📍 Kimenet: web-installer/releases/*.pacman
Arch
📦
Debian/Ubuntu
deb csomag
Debian és Ubuntu alapú rendszerekhez. APT-tel vagy dpkg-vel telepíthető.
📝 Build
./build-client-linux-debian.sh
💾 Telepítés
sudo apt install ./Cobblemon-Universe-x64.deb
📍 Kimenet: web-installer/releases/*.deb
Debian
📦
Red Hat/Fedora
rpm csomag
Fedora, RHEL és CentOS alapú rendszerekhez. DNF-fel vagy rpm-vel telepíthető.
📝 Build
./build-client-linux-redhat.sh
💾 Telepítés
sudo dnf install Cobblemon-Universe-x64.rpm
📍 Kimenet: web-installer/releases/*.rpm
Fedora
🎞️
AppImage
Universal Linux
Szinte bármilyen Linux disztribúción működik. Nem igényel telepítést.
📝 Build
./build-client-linux-appimage.sh
🚀 Futtatás
chmod +x Cobblemon-Universe-x64.AppImage && ./Cobblemon-Universe-x64.AppImage
📍 Kimenet: *.AppImage (x64, arm64)
AppImage
📦
TAR.GZ
Portable archívum
Hordozható, tömörített archívum. Bármilyen Linux-ra működik.
📝 Build
./build-client-linux-targz.sh
📂 Kicsomagolás
tar -xzf Cobblemon-Universe-x64.tar.gz
📍 Kimenet: *.tar.gz (x64, arm64)
Portable
🎁
Flatpak
Sandbox
Sandbox-os csomagolás. Magasabb biztonság és izoláció.
📝 Build
./build-client-linux-flatpak.sh
💾 Telepítés
flatpak install Cobblemon-Universe.flatpak
📍 Kimenet: web-installer/releases/*.flatpak
Flatpak
